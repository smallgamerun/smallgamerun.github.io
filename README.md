# Xyxing's Web

The source for [smallgamerun.github.io](https://smallgamerun.github.io), a bilingual portfolio and blog built with Astro.

## Local development

```bash
npm install
npm run dev
```

Run `npm run build` before publishing. The generated `docs/` directory is committed with the source and served by GitHub Pages from the `master` branch.

## Writing

Blog posts live in `src/content/blog/`. Projects live in `src/content/projects/`. Each Chinese entry has an English entry with the same `translationKey`.
